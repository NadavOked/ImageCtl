כרטיסי רשת

מה מחובר לשרת — כרטיס לכל רשת או וילן. DHCP כבוי כברירת מחדל; הדלקה דורשת הקלדת שם הכרטיס.

שםMACכתובת IPתיאורDHCP

כתובת השרת עצמו

כתובת, שער ו-DNS לכל כרטיס — נכתבים ל-interfaces.d ושורדים אתחול. הנורה משמאל אומרת מה ip addr מראה עכשיו, לא מה שהוגדר. שינוי שיכול לנתק את הקונסולה מוחזר תוך דקה אם לא אושר.

נתיבים סטטיים

נתיב שנוסף כאן נכתב לקובץ הכרטיס ונשאר אחרי אתחול — בניגוד ל-ip route add, שנעלם.

בריאות המערכת

מה שהיה דורש ss ו-journalctl בטרמינל — פורטים, dnsmasq, TFTP, השרת והכרטיסים.

‏SSH — מי יכול להיכנס, ומאיפה

המתג אומר מה ביקשנו. הנורה שלידו אומרת מה מאזין עכשיו, לפי טבלת הסוקטים של הקרנל ולפי התפריט שהשרת מגיש בפועל. כשהשניים נבדלים — מה שמאזין הוא הנכון.
